# Changelog

All notable changes to this project.

## [0.2.0] - 2026-10-28

### Features

- Added File browser at `/file-browser` to browse recent Blob clips and images (Latest / Images / Clips), copy links, edit labels, and delete assets
- Added `DELETE /api/clips` to remove exported clips and label sidecars from the public store

### Improvements

- Grouped the sidebar into Library, Media, and Review (`toolGroups` in `lib/tools.ts`)

## [0.1.0] - 2026-10-21

### Features

- Added team comments on social preview share links with a sticky comments panel
- Added Edit Preview on share pages for Cloudflare Access admins

### Improvements

- Updated README and AGENTS.md for tools, Blob previews, and Zero Trust admin access
